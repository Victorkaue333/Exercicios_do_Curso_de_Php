# Exercicios_do_Curso_de_Php

Exercícios feitos no curso PHP do Zero a Maestria + 4 Projetos incríveis

## 📚 Exercícios Disponíveis

1. **Comparação de Números** - Comparação entre valores numéricos
2. **Verificação de Acesso** - Sistema de controle de acesso
3. **Cálculo de Desconto** - Aplicação de descontos em valores
4. **Verificação de Categoria** - Classificação por categorias

## 🚀 Configuração do Ambiente

Este projeto utiliza XAMPP para executar o servidor PHP localmente.

### Pré-requisitos

- XAMPP instalado

### Como Executar

1. Certifique-se de que o XAMPP está instalado
2. Copie este projeto para a pasta `htdocs` do XAMPP (geralmente localizada em `C:\xampp\htdocs\`)
3. Inicie o Apache através do painel de controle do XAMPP
4. Acesse no navegador: `http://localhost/Exercicios_do_Curso_de_Php/`

> **Nota:** Todas as pastas deste projeto devem estar dentro do diretório `htdocs` para funcionar corretamente.
